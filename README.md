# 指标相关性 · 因果性分析平台

输入两个指标编码 → 拉取时间序列 → 多维度相关性 / 因果性检验 → 交互式可视化。

## 使用

指标编码格式：`品种|地区`，例如 `螺纹钢|全国`、`原油|英国布伦特`。

## 架构

纯静态前端，**无需后端**：

- 数据源：Mysteel MBI 接口（`Access-Control-Allow-Origin: *`，浏览器跨域直连，数据不出浏览器）
- 统计引擎：自研纯 JS 实现，零外部依赖
- 图表：ECharts 5（CDN）

## 统计维度

Pearson / Spearman / 互信息 / Granger 因果检验（双向）/ OLS 回归 R² / 滞后相关 / 滚动相关 / 描述统计

数值已与 scipy · statsmodels 逐项对齐（误差 < 1e-9）。

## 数据口径说明

MBI 接口对同一日期同时返回「真实数据」与「预测数据」两条线。分析主序列**一律优先采用真实数据**，
预测值单独保留并在图一中以虚线展示，用于观察模型预测与实际走势的偏离。
